Provedor de IA

A chave de API é sua, fica armazenada apenas neste navegador (ofuscada, não criptografada de forma forte) e é usada somente pelo processo em segundo plano da extensão.

Modelos de minuta

Escolha uma pasta local com seus modelos (.docx ou .txt). O conteúdo é indexado localmente (BM25) e nunca sai do seu computador — apenas o modelo escolhido para uma minuta é incluído no prompt.

    Hosts bloqueados

    A extensão só é ativada em páginas que parecem ser do PJe (domínios *.jus.br). Liste aqui hosts em que ela deve permanecer desligada, um por linha (ex.: pje.tjxx.jus.br).

    Dados

    Conteúdo de processos e conversas nunca é gravado em disco — vive apenas na memória da aba. O botão abaixo apaga configurações, chaves de API e o índice de modelos.
